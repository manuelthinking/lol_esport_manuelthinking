# SQL-04_create_vw_lol_team_strength_bucket

## Source SQL File
04_create_vw_lol_team_strength_bucket.sql

## Purpose
Creates a view that labels each historical team as strong, neutral, or weak.

In plain English:
This view looks at historical series wins and losses, smooths each team’s win rate toward the league/split average, and assigns a strength bucket.

This is used as one of the core inputs for Bayesian matchup logic.

## SQL Object Created
Creates:

dbo.vw_lol_team_strength_bucket

This is a view.

## Data It Consumes

### Source Table
- dbo.lol_team_series_results

The source table must already be built from historical team game/series results.

## Data It Creates
Creates a view with one row per:

- league
- season
- split
- teamname

## Grain
league + season + split + teamname

## Main Filters
The view only includes:

- league IN ('LPL', 'LCK')
- series_result IN ('2-0', '2-1', '1-2', '0-2')
- teamname IS NOT NULL

## Main Logic

### Base CTE
Pulls series result rows from dbo.lol_team_series_results.

Important fields:
- league
- year as season
- split
- teamname
- series_id
- is_series_win
- wins
- losses
- series_result
- games_played
- series_start_date

### League Priors CTE
Calculates league/split-level average win rate.

Fields:
- league_team_series_rows
- league_win_rate

Grouped by:
- league
- season
- split

### Team Record CTE
Calculates team record.

Fields:
- series_count
- series_wins
- series_losses
- game_wins
- game_losses
- first_series_date
- last_series_date
- raw_series_win_rate

### Smoothed CTE
Smooths the team win rate toward the league/split average.

Formula:

(team series wins + league_win_rate * 12)
/
(team series count + 12)

The prior weight is 12.

## Output Columns
- league
- season
- split
- teamname
- series_count
- series_wins
- series_losses
- game_wins
- game_losses
- first_series_date
- last_series_date
- raw_series_win_rate
- league_win_rate
- prior_weight
- smoothed_series_win_rate
- team_strength_bucket
- team_strength_sample_label

## Bucket Logic

### team_strength_bucket
- series_count < 5 -> neutral
- smoothed_series_win_rate >= 0.55 -> strong
- smoothed_series_win_rate <= 0.45 -> weak
- everything else -> neutral

### team_strength_sample_label
- series_count < 5 -> low_sample
- series_count between 5 and 9 -> medium_sample
- else -> solid_sample

Run when creating or updating the SQL view definition.

After new results are loaded, you do not need to rerun this file unless the view definition changed.

## Health Checks

Check view row count:
SELECT
    COUNT(*) AS rows_count
FROM dbo.vw_lol_team_strength_bucket;

Check bucket distribution:
SELECT
    league,
    season,
    split,
    team_strength_bucket,
    team_strength_sample_label,
    COUNT(*) AS teams
FROM dbo.vw_lol_team_strength_bucket
GROUP BY league, season, split, team_strength_bucket, team_strength_sample_label
ORDER BY season DESC, league, split, team_strength_bucket;

Check latest team strength:
SELECT TOP 100
    league,
    season,
    split,
    teamname,
    series_count,
    series_wins,
    series_losses,
    raw_series_win_rate,
    league_win_rate,
    smoothed_series_win_rate,
    team_strength_bucket,
    team_strength_sample_label,
    last_series_date
FROM dbo.vw_lol_team_strength_bucket
ORDER BY season DESC, league, smoothed_series_win_rate DESC;

## Important Risk Areas

### Risk 1: Depends on lol_team_series_results
If team series results are stale, strength buckets are stale.

### Risk 2: Small sample teams forced neutral
This is intentional, but it can hide a genuinely strong new team until they reach 5 series.

### Risk 3: Split is part of the grain
The view creates separate rows by split. Downstream joins must include split or risk duplicate/mismatched rows.

### Risk 4: Only LPL/LCK and BO3 paths
Other leagues and formats are excluded.

### Risk 5: Prior weight is hard-coded
The smoothing prior weight is fixed at 12.
