## Grain
Intended grain:

one row per player per team per historical series

That means a normal best-of-3 series should have up to 10 player rows:
- 5 players from Team A
- 5 players from Team B

## Position Normalization
The view normalizes positions:

- bot / adc -> BOT
- jungle / jng -> JNG
- top -> TOP
- mid -> MID
- support / sup -> SUP
- anything else -> uppercase trimmed value

Then final output filters to:
- TOP
- JNG
- MID
- BOT
- SUP

## Series Result Filter
The final output only includes best-of-3 style results:

- 2-0
- 2-1
- 1-2
- 0-2

## League Filter
The source CTE filters to:

- LPL
- LCK

## Health Checks

Check view exists:
SELECT
    OBJECT_ID('dbo.vw_lol_series_player_stats', 'V') AS object_id;

Check row count:
SELECT
    COUNT(*) AS rows_count
FROM dbo.vw_lol_series_player_stats;

Check rows by league/season:
SELECT
    season,
    league,
    COUNT(*) AS player_series_rows,
    COUNT(DISTINCT series_id) AS series_count,
    COUNT(DISTINCT player_name) AS players
FROM dbo.vw_lol_series_player_stats
GROUP BY season, league
ORDER BY season DESC, league;

Check expected positions:
SELECT
    position,
    COUNT(*) AS rows_count
FROM dbo.vw_lol_series_player_stats
GROUP BY position
ORDER BY position;

Check expected 10 player rows per series:
SELECT
    series_id,
    COUNT(*) AS player_rows,
    COUNT(DISTINCT teamname) AS teams,
    COUNT(DISTINCT position) AS positions
FROM dbo.vw_lol_series_player_stats
GROUP BY series_id
HAVING COUNT(*) <> 10
ORDER BY player_rows;

## Important Risk Areas

### Risk 1: Template placeholder
This file will fail or be invalid until dbo.YOUR_RAW_SERIES_PLAYER_TABLE_HERE is replaced.

### Risk 2: Source must be series-level
The source must already be aggregated to series level. If it is game-level, the view may duplicate data unless aggregation is added.

### Risk 3: DK points quality
Downstream Bayesian logic depends heavily on dk_points. Make sure it uses the same DK scoring logic expected elsewhere.

### Risk 4: No team/opponent mapping logic
The view expects teamname and opponent_teamname to already exist.

### Risk 5: Only LPL/LCK and BO3 paths
This is intended for your LPL/LCK DK workflow and excludes other leagues and formats.
