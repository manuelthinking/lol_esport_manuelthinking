# SQL-24_create_vw_lol_upset_resistance_signal_v1

## Source SQL File
24_create_vw_lol_upset_resistance_signal_v1.sql

## Purpose
Creates a lane-power upset resistance signal.

In plain English:
This view takes the team-level lane edge summary and converts it into DFS-friendly labels and flags. It identifies whether a favorite has clean lane support, whether the opponent has enough carry-lane resistance to threaten a sweep, or whether an underdog is live.

This is the signal layer used to interpret lane-power edges.

## SQL Object Created
Creates or alters:

dbo.vw_lol_upset_resistance_signal_v1

This is a view.

## Data It Consumes

### Source View
- dbo.vw_lol_matchup_lane_edge_summary_v1

## Data It Creates
Creates one row per:

game + team + opponent

## Grain
One row per team perspective per game.

## Main Logic

### base CTE
Reads lane edge summary metrics:
- lane edges by role
- total/carry/main/secondary lane edge
- positive/negative lane counts
- opponent resistance counts
- edge tiers

### scored CTE
Creates:
- lane_favorite_status
- opponent_carry_resistance_level
- opponent_overall_resistance_level
- carry_lane_risk_level
- negative_carry_lane_count_level

### final_scored CTE
Creates:
- upset_resistance_score
- upset_resistance_tier
- upset_signal_label
- favorite_stomp_warning_flag
- underdog_live_flag
- favorite_stomp_support_flag

## Lane Favorite Status Logic
- total_lane_edge >= 25 -> Lane Favorite
- total_lane_edge <= -25 -> Lane Underdog
- total_lane_edge >= 10 -> Small Lane Favorite
- total_lane_edge <= -10 -> Small Lane Underdog
- else -> Lane Neutral

## Upset Resistance Score
Formula:

opponent_carry_resistance_level * 2
+ opponent_overall_resistance_level
+ carry_lane_risk_level * 2
+ negative_carry_lane_count_level

Higher means more resistance or upset risk.

## Upset Resistance Tier
- score >= 8 -> High Resistance
- score >= 5 -> Medium Resistance
- score >= 2 -> Low Resistance
- else -> Minimal Resistance

## Signal Label Logic

### Favorite Stomp Support
When:
- total_lane_edge >= 25
- carry_lane_edge >= 15
- opponent_neutral_or_better_carry_lanes <= 1
- negative_carry_edge_lanes = 0

### Favorite Stomp Warning
When:
- total_lane_edge >= 25
- opponent_neutral_or_better_carry_lanes >= 2

### Favorite Carry-Lane Warning
When:
- total_lane_edge >= 10
- carry_lane_edge < 5

### Underdog Resistance
When:
- total_lane_edge <= -25
- opponent_neutral_or_better_carry_lanes >= 2

### Underdog Live
When:
- total_lane_edge <= -10
- carry_lane_edge >= -5

### Neutral / Thin Signal
When:
- ABS(total_lane_edge) < 10
- ABS(carry_lane_edge) < 5

### Standard Lane Signal
Fallback label.

## Important Risk Areas

### Risk 1: Historical actual-game basis
This view currently depends on actual historical game players and is best for historical evaluation. A live-slate version needs expected starters.

### Risk 2: Thresholds are hard-coded
The signal logic uses fixed thresholds like 25, 15, 10, and 5. These should be backtested.

### Risk 3: Resistance score is heuristic
The upset_resistance_score is a rule-based heuristic, not a trained model.

### Risk 4: Team perspective duplication
Signals are team-side. Each game has two rows.

### Risk 5: Lane-power can disagree with Bayes
This is expected. The downstream comparison view is designed to identify these conflicts.

## Recommended Future Enhancements
- Backtest thresholds by league.
- Add current-slate version using expected starters.
- Add model_version for threshold changes.
- Add separate "favorite sweep support" and "upset risk" outputs.
- Add a view that summarizes to one row per matchup.
