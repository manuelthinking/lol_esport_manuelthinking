# SQL-21_create_vw_lol_player_lane_power_rating_v1

## Source SQL File
21_create_vw_lol_player_lane_power_rating_v1.sql

## Purpose
Creates a player lane-power rating view.

In plain English:
This view takes the player lane-power base metrics and converts them into percentile-based scores by league and lane. It then combines those percentiles into one lane_power_score and assigns each player a lane-power tier.

This is the scoring layer on top of the lane-power base view.

## SQL Object Created
Creates or alters:

dbo.vw_lol_player_lane_power_rating_v1

This is a view.

## Data It Consumes

### Source View
- dbo.vw_lol_player_lane_power_base_v1

## Data It Creates
Creates one row per:

league + lane + team + player

It keeps the source player/lane metrics and adds:
- percentile scores
- weighted lane_power_score
- lane_power_rank
- lane_player_pool_count
- lane_power_tier

## Grain
One row per player/team/lane.

## Main Logic

### base CTE
Reads from dbo.vw_lol_player_lane_power_base_v1 and computes percentile scores using PERCENT_RANK().

Percentiles are calculated within:
- league
- lane

Percentile components:
- dk_score
- kill_score
- assist_score
- cs_score
- dpm_score
- damage_share_score
- gold10_score
- xp10_score
- cs10_score
- vision_score_rank
- wards_placed_score
- wards_killed_score
- first_blood_score
- win_rate_score
- death_control_score

Important:
death_control_score orders deaths_per_game descending, so lower deaths get the better percentile.

### scored CTE
Calculates lane_power_score with different weights by lane.

### ranked CTE
Ranks players within league/lane by lane_power_score.

## Tier Logic
lane_power_tier:
- lane_power_score >= 85 -> Elite
- lane_power_score >= 70 -> Strong
- lane_power_score >= 50 -> Neutral
- lane_power_score >= 35 -> Weak
- else -> Poor

## Health Checks

Check row count:
SELECT
    COUNT(*) AS rows_count
FROM dbo.vw_lol_player_lane_power_rating_v1;

Check tier distribution:
SELECT
    league,
    lane,
    lane_power_tier,
    COUNT(*) AS player_rows,
    AVG(lane_power_score) AS avg_lane_power_score
FROM dbo.vw_lol_player_lane_power_rating_v1
GROUP BY league, lane, lane_power_tier
ORDER BY league, lane, lane_power_tier;

Check top players by lane:
SELECT TOP 100
    league,
    lane,
    team,
    player_name,
    games_played,
    lane_power_score,
    lane_power_rank,
    lane_power_tier,
    avg_dk_points,
    dpm,
    avg_damage_share,
    kills_per_game,
    assists_per_game
FROM dbo.vw_lol_player_lane_power_rating_v1
ORDER BY league, lane, lane_power_rank;

## Important Risk Areas

### Risk 1: Depends on base view quality
If dbo.vw_lol_player_lane_power_base_v1 has stale or incomplete data, this rating view inherits it.

### Risk 2: Percentile scoring is relative by league/lane
Scores are not absolute. A 75 in one lane means relative to that league/lane player pool.

### Risk 3: PERCENT_RANK with small pools
Small lane/player pools can make scores jumpy.

### Risk 4: Hard-coded weights
Weights are hard-coded by lane. This is okay for v1, but should be versioned if changed.

### Risk 5: Source base view was part of a numbering conflict
The base view was previously uploaded as another file numbered 20, while ownership training also used 20. This chain should be renumbered cleanly later.
