# Script-ingest_oracle_elixir

## Purpose
Downloads or loads Oracle Elixir match data and stores LCK/LPL rows into the raw staging table.

In plain English:
It gets Oracle Elixir CSV data for configured years, filters to LCK and LPL, stores each row as JSON in staging, and refreshes a latest-starters helper table.

This is the upstream ingestion step for historical LoL match data.

## Data It Consumes

### Remote CSV URLs
The script has Google Drive URLs configured for:
- 2024
- 2025
- 2026

Current configured YEARS list:
- 2026

So in its current form, it only attempts to load 2026.

### Manual Fallback Folder
If download fails or the downloaded file is invalid, the script checks:

C:\DailyDFS\LoL\data\manual_downloads

It looks for valid CSV files containing the year in the filename.

## Target Leagues
Only these leagues are kept:
- LCK
- LPL

## Data It Creates / Updates

### Staging Table
- raw.oracle_elixir_match_data_staging

Inserted fields:
- source_year
- source_file
- row_json

Each Oracle row is stored as JSON.

### Latest Starters Table
- raw.oracle_elixir_latest_starters

The script creates this table if needed and refreshes it.

Fields:
- league
- teamname
- position
- playername
- latest_game_date
- latest_gameid
- side
- source_year
- source_file
- refreshed_at

## Refresh Behavior

### Staging Refresh
For each successfully loaded year:
1. Load and validate CSV.
2. Filter to LCK/LPL.
3. Delete existing staging rows for that source_year.
4. Insert new rows for that source_year.

Important:
The script only deletes staging rows after it successfully loads a valid dataframe.

### Latest Starters Refresh
If any year is loaded, it combines loaded rows and refreshes:
raw.oracle_elixir_latest_starters

It truncates the latest starters table, then inserts one latest player per:
- league
- teamname
- position

## Main Functions
- download_year
- find_manual_file
- load_csv
- delete_year_from_staging
- insert_df
- ensure_latest_starters_table
- refresh_latest_starters

## Data Cleaning
Column names are normalized:
- lowercase
- trim spaces
- spaces become underscores
- percent signs become pct

The date column is converted to a date if present.

Rows are converted to JSON strings before insert.

## What Uses This Data
Direct downstream script:
- Script-build_player_games

Other downstream use:

- historical player/lane/team modeling
- lane matchups
- Team Overview

## SQL Health Checks

Check staging rows:
SELECT
    source_year,
    source_file,
    COUNT(*) AS staging_rows
FROM raw.oracle_elixir_match_data_staging
GROUP BY source_year, source_file
ORDER BY source_year DESC, source_file;

Check latest starter rows:
SELECT
    league,
    COUNT(*) AS latest_starter_rows,
    COUNT(DISTINCT teamname) AS teams
FROM raw.oracle_elixir_latest_starters
GROUP BY league
ORDER BY league;

Preview latest starters:
SELECT TOP 100
    league,
    teamname,
    position,
    playername,
    latest_game_date,
    latest_gameid,
    side,
    source_year,
    source_file,
    refreshed_at
FROM raw.oracle_elixir_latest_starters
ORDER BY latest_game_date DESC, league, teamname, position;

Check staging has player rows:
SELECT TOP 20
    source_year,
    source_file,
    LEFT(row_json, 300) AS row_preview
FROM raw.oracle_elixir_match_data_staging
ORDER BY source_year DESC;

## Important Risk Areas

### Risk 1: Current YEARS only includes 2026
The script has URLs for 2024, 2025, and 2026, but currently only loads:
YEARS = [2026]

If you want a full historical refresh, this list must be changed.

### Risk 2: Google Drive download can fail
The script has manual fallback logic. If download fails, place a valid CSV in:
C:\DailyDFS\LoL\data\manual_downloads

### Risk 3: Staging row_json is flexible but less queryable
Rows are stored as JSON in staging. This is good for flexible raw storage, but downstream scripts must parse row_json correctly.

### Risk 4: Latest starters only uses loaded years from the current run
If only 2026 is loaded, latest starters are based only on 2026 rows.

### Risk 5: Only LCK/LPL are retained
This is intentional for your current DFS focus, but other leagues will be excluded.
