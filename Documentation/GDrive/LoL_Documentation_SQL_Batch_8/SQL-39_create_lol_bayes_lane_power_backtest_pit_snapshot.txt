# SQL-39_create_lol_bayes_lane_power_backtest_pit_snapshot

## Source SQL File

## Purpose
Creates the physical PIT Bayes vs Lane Power backtest snapshot table.

In plain English:
This file creates the table that stores materialized PIT Bayes/Lane Power backtest rows. The table is later populated by file 40 and indexed by file 41.

Unlike file 36, this file uses an explicit CREATE TABLE statement rather than SELECT TOP 0 *.

## Important Risk Areas

### Risk 1: Existing table is not altered
If the table already exists with an older schema, this script will not update it.

### Risk 2: No primary key or unique constraint
The table does not enforce uniqueness by target_series_id/team/opponent. Repeated refresh uses TRUNCATE first, so duplicates are unlikely if refresh works, but not structurally prevented.

### Risk 3: Depends on refresh script for data
This file creates an empty table only.

### Risk 4: Season not stored as constrained
The table can store multiple seasons, but refresh file 40 is hard-coded to season 2026.

## Recommended Future Enhancements
- Add a unique index on target_series_id/team/opponent/backtest_version.
- Add run_id or snapshot_version.
- Add explicit created_at/refreshed_at run metadata table.
- Add schema migration checks.
- Add indexes in the creation script or keep 41 as dedicated index file.
