# Script-build_lol_team_series_profiles

## Purpose
Creates a team-level historical profile table for LoL best-of-3 series outcomes.

It summarizes how each team performs in each possible series result:
- 2-0
- 2-1
- 1-2
- 0-2

This table helps determine team DFS environment, sweep upside, bloodbath potential, and TEAM-slot value.

## Data It Consumes

### Source Table
- dbo.lol_team_series_results

Only rows with these results are used:
- 2-0
- 2-1
- 1-2
- 0-2

## Data It Creates

### Target Table
- dbo.lol_team_series_profiles

This is a physical SQL table, not a view.

The script:
1. Creates the table if needed.
2. Deletes existing rows.
3. Rebuilds and inserts fresh profile rows.

## Grain
One row per:
- teamname
- league
- series_result

Primary key:
- teamname
- league
- series_result

## Custom Scores
### series_dfs_score
Higher means better overall DFS environment.

### bloodiness_score
Higher means more fight-heavy / DFS-friendly game environment.

### clean_stomp_score
Higher means a cleaner dominant win profile.

## Profile Labels
2-0 labels:
- Elite 2-0 Smash
- Strong 2-0 Producer
- Clean But Low DFS
- Standard 2-0

2-1 labels:
- Elite 2-1 Bloodbath
- Strong 2-1 Ceiling
- Bloody But Volatile
- Standard 2-1

1-2 labels:
- Live Losing Stack
- Useful Loss Volume
- Low Loss Output

0-2 labels:
- Competitive Sweep Loss
- Dead Sweep Loss

## What Uses This Data

- team stack scores
- player projections
- TEAM slot projections
- projected paths
- 2-0 vs 2-1 preferences

## Run Frequency
Run after new completed match results are loaded and after dbo.lol_team_series_results is refreshed.

This is mostly a post-results refresh script.

## Suggested Command
cd C:\DailyDFS\LoL
python .\scripts\build_lol_team_series_profiles.py

## Important Risk Areas
- Full delete and rebuild.
- Depends completely on dbo.lol_team_series_results.
- Team name consistency matters.
- Profiles currently blend all years/splits in the source table.

## Health Checks
SELECT
    league,
    series_result,
    COUNT(*) AS profile_rows,
    SUM(series_count) AS total_series_samples,
    MIN(first_series_date) AS first_series_date,
    MAX(last_series_date) AS last_series_date
FROM dbo.lol_team_series_profiles
GROUP BY league, series_result
ORDER BY league, series_result;

SELECT
    teamname,
    league,
    COUNT(DISTINCT series_result) AS result_profiles
FROM dbo.lol_team_series_profiles
GROUP BY teamname, league
HAVING COUNT(DISTINCT series_result) < 4
ORDER BY result_profiles ASC, teamname;
