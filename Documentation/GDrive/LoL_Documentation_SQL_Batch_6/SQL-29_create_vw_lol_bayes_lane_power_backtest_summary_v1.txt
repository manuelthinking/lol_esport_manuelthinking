# SQL-29_create_vw_lol_bayes_lane_power_backtest_summary_v1

## Source SQL File
29_create_vw_lol_bayes_lane_power_backtest_summary_v1.sql

## Purpose
Creates a summary view for Bayes vs Lane Power backtesting.

In plain English:
This view summarizes how Bayes and Lane Power performed across historical rows. It groups results overall, by Bayes/Lane alignment label, by upset signal, by upset resistance tier, and by Bayes favorite status.

This is the main high-level performance summary for the Bayes vs Lane Power comparison system.

## SQL Object Created
Creates or alters:

dbo.vw_lol_bayes_lane_power_backtest_summary_v1

This is a view.

## Data It Consumes

### Source Table
- dbo.lol_bayes_lane_power_comparison_snapshot

Important:
This view reads the snapshot table, not the live comparison view.

## Data It Creates
Creates a summary view with one row per:

summary_group + summary_bucket

## Grain
One row per summary bucket.

Summary groups:
- Overall
- Bayes/Lane Alignment
- Upset Signal
- Upset Resistance Tier
- Bayes Favorite Status

## Main Filter
The base CTE filters to:

actual_won_series IS NOT NULL

So only evaluated historical rows are included.

## Main Metrics
For every summary bucket, the view calculates:

- rows_count
- bayes_eval_rows
- bayes_winner_accuracy
- lane_power_eval_rows
- lane_power_winner_accuracy
- bayes_correct_count
- bayes_wrong_count
- lane_power_correct_count
- lane_power_wrong_count

## Summary Sections

### Overall
One row:
- All Matches

### Bayes/Lane Alignment
Groups by:
- bayes_lane_alignment_label

Examples may include:
- Bayes and Lane Signal Aligned or Neutral
- Bayes Favorite / Lane Stomp Warning
- Bayes Favorite / Lane Stomp Support
- Bayes Favorite / Carry Lanes Questionable
- Bayes Underdog / Lane Power Live
- Bayes Toss-Up / Lane Power Has Lean

### Upset Signal
Groups by:
- upset_signal_label

### Upset Resistance Tier
Groups by:
- upset_resistance_tier

### Bayes Favorite Status
Groups by:
- bayes_favorite_status

## Important Risk Areas

### Risk 1: Snapshot must be refreshed
This view can look valid but still be stale if file 27 has not been run.

### Risk 2: Team-side rows, not match-level rows
The source snapshot is team-perspective rows. Accuracy here is at team-side row level unless the snapshot view already controls for match-level interpretation.

### Risk 3: NULL labels become their own grouping behavior
If labels are NULL, SQL GROUP BY will create a NULL bucket.

### Risk 4: No league split
This summary does not group by league. If LPL/LCK behave differently, use more detailed queries or add a league-level summary view.
