# SQL-33_create_vw_lol_matchup_lane_edge_summary_pit_v1

## Source SQL File
33_create_vw_lol_matchup_lane_edge_summary_pit_v1.sql

## Purpose
Creates a point-in-time team-level lane edge summary.

In plain English:
This view rolls up point-in-time lane edge rows into one row per target series/team/opponent. It summarizes whether a team had an edge across all lanes, carry lanes, and main carry lanes before the series happened.

This is the PIT equivalent of the historical lane edge summary view.

## SQL Object Created
Creates or alters:

dbo.vw_lol_matchup_lane_edge_summary_pit_v1

This is a view.

## Carry Lane Definitions
carry_lane_edge includes:
- JNG
- MID
- ADC

main_carry_lane_edge includes:
- MID
- ADC

secondary_lane_edge includes:
- TOP
- SUP

## Tier Logic

### total_lane_edge_tier
- rated_lane_rows < 3 -> Thin PIT Rating
- total_lane_edge >= 50 -> Massive Overall Lane Edge
- total_lane_edge >= 25 -> Strong Overall Lane Edge
- total_lane_edge >= 10 -> Moderate Overall Lane Edge
- total_lane_edge > -10 -> Mostly Even Overall
- total_lane_edge > -25 -> Moderate Overall Lane Disadvantage
- total_lane_edge > -50 -> Strong Overall Lane Disadvantage
- else -> Massive Overall Lane Disadvantage

### carry_lane_edge_tier
- rated_lane_rows < 3 -> Thin PIT Rating
- carry_lane_edge >= 30 -> Massive Carry Lane Edge
- carry_lane_edge >= 15 -> Strong Carry Lane Edge
- carry_lane_edge >= 5 -> Moderate Carry Lane Edge
- carry_lane_edge > -5 -> Mostly Even Carry Lanes
- carry_lane_edge > -15 -> Moderate Carry Lane Disadvantage
- carry_lane_edge > -30 -> Strong Carry Lane Disadvantage
- else -> Massive Carry Lane Disadvantage

## Important Risk Areas

### Risk 1: Missing upstream file 32
This view depends on dbo.vw_lol_matchup_lane_edges_pit_v1, but that SQL file was not included in this batch.

### Risk 2: Thin PIT ratings
If fewer than 3 rated lanes are available, the view labels the row as Thin PIT Rating.

### Risk 3: Missing lane rows affect totals
If the upstream edge view lacks players/ratings, total and carry edges can be incomplete.

### Risk 4: Team perspective rows
Rows are team-side, not one row per match.

### Risk 5: Historical PIT only
This is built for historical backtesting, not directly for upcoming slate analysis.
