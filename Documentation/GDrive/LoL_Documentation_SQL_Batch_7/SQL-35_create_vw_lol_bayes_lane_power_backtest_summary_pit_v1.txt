# SQL-35_create_vw_lol_bayes_lane_power_backtest_summary_pit_v1

## Source SQL File
35_create_vw_lol_bayes_lane_power_backtest_summary_pit_v1.sql

## Purpose
Creates a summary view for the point-in-time Bayes vs Lane Power backtest.

In plain English:
This view summarizes whether Bayes and Lane Power predicted winners correctly across the PIT backtest view. It groups results overall, by Bayes/Lane alignment label, by Bayes favorite status, and by upset resistance tier.

This is the high-level performance summary for the PIT lane-power backtest.

## SQL Object Created
Creates or alters:

dbo.vw_lol_bayes_lane_power_backtest_summary_pit_v1

This is a view.

## Data It Consumes

### Source View
- dbo.vw_lol_bayes_lane_power_backtest_pit_v1

## Data It Creates
Creates one row per:

summary_group + summary_bucket

## Grain
One row per summary bucket.

Summary groups:
- Overall
- Bayes/Lane Alignment
- Bayes Favorite Status
- Upset Resistance Tier

## Main Filter
The base CTE filters to:

actual_won_series IS NOT NULL

So only evaluated historical rows are included.

## Main Metrics
Each summary row includes:

- rows_count
- bayes_eval_rows
- bayes_winner_accuracy
- lane_power_eval_rows
- lane_power_winner_accuracy
- thin_pit_rows

## Important Risk Areas

### Risk 1: Depends on file 34
If the PIT backtest view fails, this summary fails.

### Risk 2: Team-side interpretation
The source view is team-perspective rows. The summary is not necessarily one row per match.

### Risk 3: No league/date grouping
This summary blends leagues and dates unless manually filtered with another query.

### Risk 4: Lane Power eval rows may be lower
Lane Power does not evaluate rows where rated_lane_rows < 3 or carry edge is too close. This is why lane_power_eval_rows may be smaller than rows_count.

### Risk 5: Thin PIT rows matter
thin_pit_rows is included and should be watched. A high thin PIT count means lane-power evidence is sparse.
